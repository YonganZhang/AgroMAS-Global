# AgroMAS-Global

**Coupling climate, watershed, market and satellite priors for closed-loop winter wheat nitrogen management**  
**耦合气候、流域、市场与卫星先验的冬小麦全季闭环精准氮肥调控**

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

`AgroMAS-Global` is a five-specialist numerical collaborative control framework for seasonal winter wheat topdressing across heterogeneous climate warming trajectories, urban drinking-water watershed nitrate surplus ceilings, fertilizer price shocks, green policy subsidies, and sensorless cross-continental transfers, independently evaluated over the mechanistic **WOFOST81-SNOMIN** (`pcse`) crop–soil simulator.

---

## Key Scientific & Methodological Highlights

- **Five-Specialist Coupled Control (`NUE_PCSE-Gym/pcse_gym/agromas_v8/`)**:
  1. **Spatial Twin Specialist**: Compact 3-seed multilayer perceptron surrogate (`13,155` weights, `55.4 KB` per checkpoint; `166.3 KB` total vs `275.52 MB` per 64-tree `ExtraTrees` ensemble — over **1,690×** serialized storage compression) + two-stage causal separation of hydraulic soil Ridge baselines (`Static3`) from site-demeaned annual satellite anomaly vectors ($\Delta \mathbf{e}_{s,t-1}$).
  2. **Climate Forecast Specialist**: De-shifted warming analogue weather branching preserving daily precipitation clustering under elevated temperature and $\text{CO}_2$ scenarios.
  3. **Urban Eco-Safety & Socio-Economic Policy Specialists**: Continuous bilateral corridor retention across EUNEP targets ($0.50 \le \text{NUE}_{\text{app}} \le 0.90$, $0 \le S_N \le S_{\text{cap}}$) preventing both profit-driven soil humus depletion and strict-cap empty-set deadlocks.
  4. **Core Agronomic Specialist**: Three-stage non-anticipative dynamic continuation enforcing a 14-day minimum inter-application interval and shared `220 kg N ha⁻¹` budget masks.
- **Independent External Physical Referee**: Unmodified `WOFOST81-SNOMIN` (`pcse` pinned at `ec31715` + 3-line project-local runtime storage patch in `patches/pcse-local-runtime.patch`).
- **Headline Verified Findings**:
  - **6.27×** historical compliance improvement over profit-only bare relaxation (`25.06%` vs `4.00%`), while tying full-budget `MaskablePPO` (`46/52` farm-years) and `DVS-N2` (`47/52`) under mild historical conditions.
  - **50.0% relative gain** over matched `SensorlessPPO` on the independent 7-season Wageningen benchmark (`28.57%` vs `19.05%`, `DVS-N2` at `0.00%`).
  - **+5.15 pp** (`+1.8°C`) and **+5.61 pp** (`+3.5°C`, zero loss cells) compliance lead over `PPO` at the operational `40 kg N ha⁻¹` cap, widening to **+7.19 to +8.10 pp** under doubled (`2×`) fertilizer prices.
  - **0% → 60.00%** (`72.02%` prediction rows) cross-continental (`LORO`) prior gate admission via station-demeaned causal satellite anomalies, paired with transparent cross-regional prediction-error reporting.
  - **100% double-precision numerical mass-conservation integrity** across `6,104,146` daily transitions (`max |ΔN| = 1.904e-11 kg ha⁻¹`, `max |ΔC| = 2.115e-10 kg ha⁻¹`).

## Quick Setup & Reproduction

```bash
# 1. Clone repository
git clone https://github.com/YonganZhang/AgroMAS-Global.git
cd AgroMAS-Global

# 2. Install Python dependencies (see reports/requirements.lock) and unmodified upstream PCSE
git clone https://github.com/ajwdewit/pcse.git
git -C pcse checkout ec31715
git -C pcse apply ../patches/pcse-local-runtime.patch
pip install -e ./pcse -e ./NUE_PCSE-Gym

# 3. Run unit & invariance verification tests
pytest NUE_PCSE-Gym/tests -q

# 4. Regenerate bilingual manuscript Markdown & captions from frozen ledgers
python3 scripts/phase8d-write-topsci-manuscript.py
```
